# ImaNewbie Does Britannia: Collector's Edition

Tryon's (Mike Hanley's) Ultima Online webcomic, 1998 to 2001, rebuilt from the Collector's Edition CD as a static site for GitHub Pages.

## What's here

- `imatoons/`: 140+ episodes of the toons, plus the 8-facet Player's Guide parody
- `enquirer/`: The Britannia Enquirer, 18 issues
- `main/`: introduction, cast of characters, themes and controversies
- `dictionary/`: Dictionary of UO/ICQspeak

## Changes from the CD

- Frames and table layouts replaced with one responsive template (`shared/site.css`)
- Prev/Next navigation on every episode and Enquirer issue; arrow keys work too
- Text converted from Windows-1252 to UTF-8
- All filenames lowercased so links work on case-sensitive hosting
- Removed unused files: BMP originals, WS_FTP logs, Paint Shop Pro and Corel files, old nav buttons
- Fixed 2 broken links from the original (`#43a` and `#123` on the Controversies page)

Comic text and art are unchanged.
